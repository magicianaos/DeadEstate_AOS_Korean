# 데드 에스테이트(Dead Estate) 한글패치 — KR-AOS

Dead Estate (Steam) 비공식 한국어 패치입니다. 메뉴·아이템·무기·업적·도전·NPC 대사·갤러리·크레딧·애냐 모드까지 화면 글자 약 4,800줄을 캐릭터 말투에 맞춰 번역했습니다.

## 받기

**[최신 릴리즈 받기](https://github.com/magicianaos/DeadEstate_AOS_Korean/releases/latest)** — `DeadEstate_KR_Patch_v*.exe` (런처)와 검수표 xlsx

## 설치

1. Steam을 켜고 게임을 구매한 계정으로 로그인, 게임은 종료합니다.
2. 런처 exe 실행 → **[패치 설치하기]**
3. Steam에서 Dead Estate 실행 → 한국어로 표시됩니다.

되돌리기: 런처 **한글패치 › 원래대로 되돌리기** 또는 Steam "게임 파일 무결성 검사".
게임이 업데이트되면 한글이 꺼지며, 새 한글패치가 나오면 다시 설치해 주세요.

배포 파일에는 게임 파일이 들어 있지 않으며, 런처가 내 PC에 설치된 정품 게임의 원본에 번역 변경분을 적용합니다. 한글 글꼴은 갈무리(Galmuri, SIL OFL 1.1)를 사용했습니다. 비공식 팬 번역이며 게임의 저작권은 원 개발사(Milkbar Lads)에 있습니다.
